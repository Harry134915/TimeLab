# Validation

## 2026-07-26 第二阶段验证

### 自动化

* Debug 全量测试：64 / 64 通过
* 覆盖计时就绪、运行、暂停、停止、完成、循环和保存失败重试
* 覆盖并发退出等待、放弃活动计时和保存失败后的命令恢复
* 覆盖进程内并发写入、独立进程锁等待和锁持有进程异常终止后的恢复
* 覆盖有效临时文件恢复、损坏临时文件隔离和主文件损坏备份

### 真实 Windows UI Automation

验证环境的实际 DPI 为 144（150%），应用窗口为 Per-Monitor V2：

* 28 个已启用、可聚焦的交互控件均具有可访问名称
* 任务输入框可以通过 UI Automation 获得键盘焦点
* 深浅色开关可以切换并恢复原状态
* 输入非法计划时长后收到真实 `LiveRegionChanged` 事件
* 应用在验证期间保持响应

### 多 DPI 有效尺寸

在实际 150% DPI 窗口中，按以下逻辑工作区尺寸调整窗口并检查滚动模式：

* 125% 笔记本有效尺寸：纵向滚动可用
* 150% 笔记本有效尺寸：宽度保持原布局，纵向滚动可用
* 200% 桌面有效尺寸：纵向滚动可用
* 200% 紧凑有效尺寸：横向、纵向滚动可用，滚动位置可以正常改变

正常 1000 × 640 DIP 布局保持不变，横向和纵向均不出现工作区滚动条；仅在可用空间不足时启用对应方向的滚动。

### 仍需设备人工复核

代码已监听 Windows 高对比度变化并映射系统颜色，但当前验证设备未全局开启高对比度。Narrator 的真实语音内容、不同显卡下的跨显示器 DPI 切换仍应在对应设备上人工复核。
