# MVP

## 当前 MVP+ 功能范围

TimeLab 当前已经完成基础 MVP，并在 UI 和番茄钟体验上加入了一些轻量增强。项目仍以简单、清晰、可运行为优先目标。

### Todo

* 创建任务
* 为任务设置计划时长
* 标记任务完成
* 删除任务
* 选择任务并关联到计时器

### Timer

* 开始计时
* 暂停计时
* 停止计时并生成 Session
* 清除当前计时状态
* 手动正计时
* 预设时长倒计时
* 专注 / 短休 / 长休模式
* 按模式提供常用预设时长
* 循环番茄模式，可设置专注时长、休息时长和轮数
* 到时提醒、提示音和界面通知

### Session Log

* 计时结束后记录 Session
* 保存开始时间、结束时间、时长
* 保存 Session 所属模式：专注、短休或长休
* 保存关联任务 ID
* 删除 Session 记录
* 显示今日专注次数、专注分钟数和完成任务数

### UI

* WPF 主界面
* Todo、Timer、Session Log 集成显示
* 浅色 / 深色模式切换
* 系统托盘隐藏、显示和提醒
* 快捷键：
  * Space：开始 / 暂停
  * Esc：停止 / 清除
