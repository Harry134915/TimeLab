# Product

## Overview

TimeLab 是一个用于记录和管理个人时间的本地工具。

它提供：

* Todo 列表，用于记录和完成任务
* 番茄钟，用于专注、短休和长休计时
* Session Log，用于保存专注和休息记录
* 轻量统计，用于查看今日专注次数、专注分钟数和完成任务数

---

## Goals

* 帮助用户记录时间使用情况
* 提供简单可用的专注计时工具
* 将任务和专注记录关联起来
* 使用本地 JSON 存储，保持项目简单
* 为后续数据分析或 AI Insight 提供基础数据

---

## Current Features

### Todo

* 创建任务
* 设置任务计划时长
* 标记任务完成
* 删除任务
* 将任务关联到计时器

### Timer

* 开始、暂停、停止和清除计时
* 正计时和预设倒计时
* 专注、短休、长休模式
* 循环番茄模式
* 到时提醒和提示音
* 保存失败后的暂停与重试
* 活动计时退出确认

### Session Log

* 自动记录 Session
* 记录开始时间、结束时间、时长、模式和关联任务
* 删除历史 Session
* 显示今日统计

### UI Experience

* WPF 主界面
* 浅色 / 深色模式
* 系统托盘
* 快捷键操作
* 表单验证、空状态和无障碍状态反馈

---

## Non-Goals

* 不做复杂任务管理，如子任务、优先级系统、标签分类
* 不做团队协作
* 不做云同步
* 不做数据库存储
* 不做复杂统计图表
* 当前阶段不实现 AI 分析

---

## Core Concepts

* Task：任务，包含标题、完成状态、创建时间、完成时间和计划时长
* Timer：计时器，包含当前状态、开始时间和已用时长
* FocusMode：计时模式，包括专注、短休和长休
* Session：一次专注或休息记录，包含时间范围、持续时长、模式和关联任务
